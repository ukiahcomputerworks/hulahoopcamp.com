# HulaHoopCamp.com

Static GitHub Pages website for the 11th annual Grateful Flow Gathering at the Barefoot Forest Homestead.

## Publishing

GitHub Pages serves the `docs` folder from the `main` branch. The custom domain is declared in `docs/CNAME`.

## Routes

- `/` gathering overview
- `/contact/` contact and signup handoff
- `/arrival/` arrival and off-grid preparation
